# Demeure Guinée — Administration

Frontend Next.js indépendant pour l’administration.

## Développement

```bat
cd /d "C:\Users\Ibrahima Djogo\Desktop\immobilier-admin"
npm install
npm run dev
```

URL : http://localhost:3001

Site public : http://localhost:3000

## Build

```bat
npm run build
npm start
```

## Variables

Voir `.env.example` :

- `NEXT_PUBLIC_API_URL` (future API)
- `NEXT_PUBLIC_PUBLIC_SITE_URL` (site public)
